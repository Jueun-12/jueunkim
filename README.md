# Jueun Kim

Personal academic website. Plain HTML and CSS, for GitHub Pages.

## Portrait

The homepage photo is `images/portrait.jpg`. Replace that file if you want to use a different picture, and keep the same filename.

## Publish on GitHub Pages

In the GitHub repository: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.

The site will appear at:

https://jueun-12.github.io/jueunkim/

## Edit the site

- Homepage text: `index.html`
- Colors and fonts: `css/styles.css`
- Other pages: `research.html`, `teaching.html`, `about.html`
